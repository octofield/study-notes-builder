# C. 考前大抄

適用於考試可以帶一張紙（或少數幾張）的情境。成品是繁體中文 PDF，多欄、高密度、分章配色。預期會經過 3–5 輪調整。

## 目錄

1. 先問清楚的限制
2. 內容怎麼選
3. 版面與配色
4. 自動縮放字級
5. 整合作業與錯誤標示
6. 製作流程

## 1. 先問清楚的限制

動手前確認：紙張大小與單雙面、考試是否另外提供某些表格或公式表（若有，使用者通常會要求不要重複放進大抄）、考試規則的文字不要放、課程有沒有特殊的作答格式要求。

課程的作答格式要求也要寫進大抄。例如某些課程要求證明必須「逐步推導並寫出所用定理的名稱」，不能用列舉或查表代替，大抄就應收錄這些定理的名稱與寫法範例。

## 2. 內容怎麼選

優先順序：

1. **老師明講會考的技巧**：獨立做一個醒目標示的詳細步驟區塊，完整收錄該技巧的標準證明或解題流程，以及作業中用過它的例子
2. **作業中出現過的題型與正確解法**
3. **各章的定義、定理、公式**
4. **簡單例子盡量壓縮**，一行帶過

理由：一張紙的空間有限，寫「看到題目時想不起來的東西」比寫「一看就懂的東西」更有價值。

## 3. 版面與配色

- 依章節或標籤類型上色（定義、定理、公式、例題、易錯點用不同顏色），一眼就能在考場快速定位
- 標題縮小，不要浪費版面
- 多欄排版，每頁三欄左右
- 密度要高，但字級不能小到考場看不清楚

## 4. 自動縮放字級

用 HTML＋CSS 多欄排版，用 Playwright／Chromium 轉成 PDF。字級用二分搜尋決定：反覆調整字級，檢查最後一欄是否溢出，找出「剛好塞滿」的最大字級。實作時：

1. 設定字級變數，載入頁面
2. 用 JS 檢查內容是否超出最後一欄或超過頁數
3. 二分搜尋字級，直到找到最大的不溢出值
4. 轉出 PDF，再轉成 PNG 逐頁目視檢查

## 5. 整合作業與錯誤標示

- 使用者拍照上傳的黑板筆記或作業若有看不清楚的地方，補上正確的推導，並說明是補的
- 發現使用者的作業答案有疑點，要明確指出並請使用者對照官方解答。常見的疑點有：結論方向寫反、少了某個推理步驟、推論規則的順序錯誤、格式嚴格度不符課程要求
- 有歧義的題目（例如符號正負不確定）列出兩種可能，不要自己選一個就當作正確

## 6. 製作流程

1. 確認限制（第 1 節）
2. 收集全部來源：課堂筆記、投影片、作業
3. 先排內容優先順序，再排版
4. 產出 v1，檔名帶版本，例如 `課名_期中大抄_v1.pdf`
5. 預期會有 3–5 輪調整（配色、標題大小、簡化例子、加入作業、加詳細步驟區塊），每次改版遞增版本號，不要覆蓋舊版
6. 最後的回覆列出疑似錯誤與需要核對的地方
